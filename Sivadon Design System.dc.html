One brand, applied consistently, everywhere we show up.

Contrast — one thing to fix

White text on Sivadon Green reads 2.8:1 and on Orange 2.5:1. Both fail AA at any size. The live Submit button and the green buttons currently do this. Use Mono 100 text on brand fills instead — it clears AA comfortably and looks sharper.

Max content width 1280px. Radius: 16px on buttons, inputs and cards; 24px on pills and toggles; 999px only on avatars. Never mix radii inside one component. Breakpoint is 992px, matching the site's mobile menu.

Elevation

The live site uses one hard shadow, 2px 2px 2px rgba(0,0,0,0.2), on form inputs. It reads as a print artefact. Replace it with this three-step scale.

Flat — resting
1px border, no shadow. Cards, inputs.
Raised — hover
0 2px 8px rgba(25,25,29,0.08)
Floating — overlay
0 12px 32px rgba(25,25,29,0.14). Menus, modals, toasts.

Motion

Logistics moves things on time. Our interface should feel the same: quick, no bounce, no overshoot. Hover a row to see it.

Hover, focus, colour120ms ease-out
Dropdown, accordion200ms ease-out
Modal, drawer, page320ms ease-out
Scroll revealfade + 16px rise, once

Never animate more than opacity and transform. Honour prefers-reduced-motion — the site's scroll-reveal animations currently ignore it.

Iconography

These are the icons the live site actually ships. Four of them are arrows, drawn four different ways: a downloaded circled arrow in the mega-menu, a second arrow inside the CTA button, and a separate pair for the carousel. Add two Material-style contact glyphs and the stroke weights stop agreeing entirely. The rule going forward: one family, outline only, 1.75px stroke on a 24px grid, round caps and joins, no fills. 24px in interfaces, 40px in marketing, always Mono 100 or Sivadon 80.

Page patterns

Components assembled into the four blocks the site actually repeats. Build new pages from these rather than inventing a layout each time.

Green-emphasis heading

The service pages set one phrase of a heading in Sivadon 80. It is the most distinctive thing the brand does typographically, and it currently happens by hand. The rule: one phrase per heading, two to four words, always the phrase carrying the claim — never the whole line, never a second phrase.
